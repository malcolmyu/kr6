# 投石塔 C：防卫区域正式实体与原版绘制

依据为 APK `gc64/kr6` 的陷阱、眩晕、mod_lifecycle、mod_stun 及真实 simulation/render 系统执行；反编译仅辅助阅读。完整目标仍是 Vue + TypeScript + Three.js 网页还原至3-2。

## 实现

CatapultTrapsRuntime 现在按实际弹体落地创建/排队/插入陷阱，在其全局实体位置执行 main。抛射时捕获原始来源ID，首次 main 查找来源并加入它的 active_traps；数量限制读取该真实列表，卖塔/重建不会把旧陷阱注册到新塔。布置候选读取全部实际陷阱位置，保留原版距离约束与随机顺序。

set动画结束进入ready；静态ready保留已有sprite.ts（原始执行证实，不能按表面animation_start调用假设重设）。有效SSO目标触发activate，等待12/30秒后重新查询，逐目标先创建damage，再掷伤害，再创建/排队stun，统一health阶段应用。动画结束隐藏、从捕获的来源列表移除自身并排队删除。来源在飞行中或区域存续时卖出，原始载荷和后续伤害仍独立执行。

眩晕共用实际mod_stun插入/更新/删除，补齐本模板生命周期：同级只刷新时间；高等级替换旧级并继承旧光效时钟；低等级拒绝；按等级持续1/2/3秒；独立stun_count、位置引用、大小/偏移/翻转、死亡/免疫与到期移除。高等级替换不重启动画，是实际原版整链发现的差异。

真实触发还暴露了旧通用bomb在damage_max=0时创建零伤害事件的问题。现按原版bomb.update的dmax>0条件跳过该伤害分支，保留FX/音效/载荷与删除顺序；陷阱弹不再制造额外damage ID。

三项投石塔效果同时改用原始z/Y/draw_order/实体ID绘制键：A焦油和B二次爆炸落在原始1400地面层；C陷阱位于3000场景层，眩晕按原始draw_order=20与身体共同遮挡，不再使用旧的固定前景带。
