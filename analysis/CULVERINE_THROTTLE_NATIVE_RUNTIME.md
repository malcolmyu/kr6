# Culverine C：火力全开

原始依据为 APK `gc64/kr6` 实体、LuaJIT脚本和真实系统执行。模板、附件和反编译文本仅作为行为证据。

正常三级购买价格150/200/250，发数3/6/9，25秒冷却。控制器在原始普通攻击收尾点接入优先判断，完整还原装填、增益准备、等待有效目标、逐发重选/丢失目标时保留落点、开火、休止/射速等待及最后普通装填。连射途中消费升级后的新发数、弹片替换和弹体配置，不提前改变正在蓄力的一发。

前景与后景为真实独立EXO实体，位于原版 tower-position（本塔range_offset.y=18）。后景每次发射重置自己的动画时钟。两层最初都进行20/30秒淡入：前景在淡入完成后移除时启动反向淡出；若淡入未完成就被移除则直接删除；后景始终直接删除。卖塔按原版remove钩子清理引用。通用timed阶段现在保留并尊重原始disabled，避免错误地按动画runs提前删掉两层光效。

准备音效的每次请求带原始delay=21/30，已通过GameSession→WorldRenderer→App→AudioManager完整传递；WebAudio实际start时间覆盖事件级延迟、定义默认延迟、显式0、解码迟到、暂停恢复剩余延迟与重启取消。
