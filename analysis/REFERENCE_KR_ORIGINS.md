# 旧版复刻项目参考评估

来源：https://github.com/malcolmyu/kingdom-rush

本次读取版本：`e3c4d4bfce4b764a99b20200be184a5a918318cf`。只读参考检出位于 `reference/kingdom-rush-1`，未合并其源码或资源。README 将目标称为《王国保卫战：起源》，其版本规则不能替代本项目 KR6 APK 的规则。

## 适合借鉴的部分

| 模块 | 已阅读的具体机制 | 本项目应用位置 |
| --- | --- | --- |
| `web/scene-transition.mjs` | 展示时钟独立于战斗时钟；关门后准备场景；serial 令牌取消失效加载；切换期间保存并恢复输入状态 | 启动、地图进入战斗、退出战斗的完整切场流程 |
| `web/save-slots.mjs` | 三个存档行、空档/已用/删除确认状态；行内确认；退出时取消尚在播放的动画 | 原版主菜单与存档管理 |
| `web/audio-settings.mjs` | 音乐与音效分别持久化；音量限制到 0–1；解除静音恢复此前音量 | 设置菜单与音频总线 |
| `web/tower-menu.mjs` | 原版菜单布局驱动；根据文本实际高度调整提示框；边缘换侧定位；与摄像机协调 | 建塔、升级、技能说明的菜单表现 |
| `web/repository.mjs` | 版本化数据边界；按关卡加载；图片 Promise 缓存；失败后删除缓存允许重试；存档标准化 | 关卡资源加载和存档升级 |

其中场景切换生命周期、解码图片缓存和三存档状态组织已作为实现方法借鉴；未复制该项目源码或资源。动画时长、坐标、文案、存档字段和各类音效仍需要用 KR6 的 Lua、EXO 与视频核验，不能直接照搬旧版常量。

## 不直接移植的部分

- `web/domain.mjs` 的路线距离、战斗、兵营、技能和伤害算法依赖起源的数据与近似。不能用其可运行状态作为 KR6 数值正确的证据。
- 原项目使用原生 JS Modules、Canvas 和 DOM。本项目继续采用 Vue、TypeScript、Three.js，迁移边界以纯状态和接口为主。
- 本项目已有原生 EXO 动画、图集、声音、逐帧 Lua 对照和负边距九宫格实现。已有原始证据支持的部分保留，避免退回通用替代动画。
- README 自身记录了仍未达到 1:1 的界面和行为差异；参考项目通过测试不代表本项目已达到用户视频标准。

更新：已在 KR6 的 SceneTransitionController/SceneTransition 中采用独立展示时钟、异步串号、过期回调取消和输入占用的结构。视觉使用 KR6 原始 loadingDef22/23帧、剑形加载指示器及本 APK 音效，并未套用起源的滑门动画。其余参考模块仍待对应流程实现；见 STARTUP_TRANSITIONS.md。

后续更新：音乐/音效独立设置的状态组织也已参考后落地；窗口生命周期、静音恢复、滑块、音频暂停续播与手机确认流程都采用 KR6 原始函数/资源和执行轨迹。当前四级塔技能菜单继续使用本 APK 的数据，旧项目的战斗数值仍未移入。
