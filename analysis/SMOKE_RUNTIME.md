# 暗影刀锋烟雾弹实际调度

本轮修正上一轮皇家敕令高级输入中的首个整局差异。网页此前在主脚本之前直接生成烟雾贴花并抽取随机数；原版由暗影刀锋自身 main 先排队光环，下一 flush 的光环 insert 才生成七团烟雾，再由光环 main 选择并排队闪避修饰器。实现位于 SmokeRuntime.ts、EnemySkills.ts、GameSession.ts、RuntimeEntities.ts 和 WorldRenderer.ts。

依据为 APK 原始 scripts_game.lua:1935、1997、2035、2047、2083，以及 all/scripts.lua:3938、4490、mod_lifecycle 的刷新规则和原版渲染/tween。相关原函数与反编译在 analysis/function-bytecode、analysis/functions/shadow_*；原始执行比反编译重建控制流更权威。

## 实现行为

- 暗影刀锋在自己的实体主脚本中判断低血量、可施法与出口节点条件，保留施法等待，治疗、忽略伤害与全可见性禁用，然后排队光环，动画结束后排队无奖励退场。退场主体保留到下一 flush。
- 开始施法时清零 motion.speed。固定随机数输入最初在 1265 帧出现泽菲拉朝向差异，原因是旧移动速度令英雄预测错误；查验原版该敌人速度后修正，并重新通过全帧检查。
- 等待期间的眩晕/死亡取消，以及等待截止帧先检查时长、再检查取消条件，按原 U.y_wait 次序执行。30 组原函数测试覆盖 0、1、7、120、1262 起始 tick、HP/节点边界、眩晕重试、死亡取消和截止帧眩晕。原版不会在已经等满的截止帧因眩晕取消。导出数据的帧时间恢复到原始 n*(1/30)，避免 JSON 小数截断造成多等一帧。
- 光环入场重置时钟并落在原版道路中心节点，创建七个真实贴花，依次抽取 0–15 帧动画偏移。光环自己的 main 按原 0.2 秒周期、完整实体表顺序与椭圆/可见性筛选目标。首次周期判断仍保留浮点减法结果，不强行在第一 main 无条件命中。
- 修饰器下一 flush 生效；同级重复应用仅刷新旧 modifier.ts，拒绝新实体。修饰器保留原精灵时钟、翻转、偏移和目标位置引用，直到实际移除才撤销闪避。
- 烟雾安装真实 dodge 组件，并在移除时恢复先前组件。基础弓箭和骑士命中、既有通用近战路径接入随机闪避与原 pop_miss，而不是只有时间到期标志。48 组原 unit_dodges / show_dodge_pop 用例核对眩晕、不可闪避伤害、近远程、共享随机调用、提示位置/旋转、active 复位与旧组件恢复。该 helper 证据不覆盖所有英雄技能的攻击时序。
- 光环退出后，七团贴花从实际 remove 回调时刻反向淡出，各自 tween 排队移除；网页仅绘制已入场的贴花与修饰器，避免提前显示或提前消失。
