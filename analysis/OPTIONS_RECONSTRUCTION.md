# KR6 pause and audio settings evidence

2026-11-15. This batch adds the APK's complete mobile pause window. It does not establish desktop-video options parity or complete the overall goal.

## Sources and platform boundary

- `gc64/kr6/data/kui_templates/popup_ingame_options.lua`, `slider_options.lua`, `group_slider_knob.lua`, `popup_message.lua`: original mobile wood/metal panel, two music/SFX toggles and sliders, restart/quit, confirmation images, labels, anchors and nine-slices. Original phone popup content base scale is1; tablet=.6, from `sequels/game_gui.lua` base_scale_list.
- `sequels/kviews_gg_sequels.lua`1842/1998: callback wiring and show state. Mobile restart/quit open a message confirmation and only confirmed action sets skip_resume and calls restart/map. Close uses GUIButtonOut and resumes. Music and SFX settings independently retain the last non-zero value for the life of the window and default to1 when an initially zero value is re-enabled. Mobile changes save immediately.
- `GG5PopUp`340/385/450: original.25s show, alpha in half that time, slide-60 with out-back; .15s out-quad hide and background fade, responder/focus restoration. Real klove.tween/HumpTimer traces are exported, including enable/hide callback frames.
- `GG5Slider`2490/2603/2611/2631: background click uses the full background width; knob drag uses the fill span; keyboard left/right uses1/25 of range. Zero volume switches knob image but retains its input handlers. Only style='sfx' previews GUISpellRefresh; this APK mobile template has no style on these sliders, so no invented preview is added.
- `all/sound_db.lua`487/496: pause/resume applies to all existing active source groups. New UI voices can still play; the paused flag is not read as a global audio-context suspend.520/537 apply separate FX and MUSIC gains. FX includes GUI. Existing sound gain/group factors remain separate.
- Desktop platform path uses `popup_options_desktop.lua` and GG5PopUpOptionsDesktop2666. Desktop restart/quit are direct calls; the mobile confirmation flow must not be described as desktop behavior. The APK has desktop KUI templates but **no desktop options atlas frames/images**: raw binary search for `gui_popups_desktop_KR6_9slice_popup_bg_` finds only KUI templates, not atlas metadata. The only popup image group is mobile `gui_popups-1.pkm.lz4`/metadata, converted losslessly to PNG. Current game HUD is desktop, so the new APK-mobile pause window remains a documented platform appearance gap against the video. Main-menu/map options and desktop pages remain pending; don't claim parity.

## Implementation

- `export_options.lua` exports28 original images, expanded templates/Chinese labels, popup frame poses,42 actual native audio/toggle/action states and14 original slider poses. Test oracle payloads stay in analysis rather than being shipped as runtime state. Popup label initialization overwrites both template 'OK' placeholders with original BUTTON_YES/BUTTON_NO strings.
- `AudioSettings.ts` stores separate music/FX levels, clamps invalid persisted input, remembers non-zero values in memory for the native window lifetime, exposes explicit save. Each new level resets that window memory from the current saved preference: persisted zero re-enables to default1, whereas repeated opens within a level retain the remembered nonzero value. Mobile App commits on each change; preferences are global across game slots, as original storage settings are.
- `AudioManager` adds separate buses, preserving existing per-sound pitch/gain/random-choice order and group factors. Pause stops/recreates Web Audio sources with preserved pitch-adjusted offset, loop wrapping and remaining start delay. Existing UI sources also pause; newly created UI sources can play. Stale ended callbacks cannot remove resumed voices. Stop/group replacement/disposal clean paused and active voices.
- `NativeSlider.vue` draws original background/fill/knob/disabled/glow, preserves distinct background-click/knob-drag mappings and native keyboard step, and uses native image bounds for knob input. `NativePopup.vue` consumes original frame poses rather than approximating CSS easing. `PauseOptions.vue` owns the confirmation window and leaves battle paused on cancel.
- App pauses/deselects/hides battle controls, resumes battle and audio when native close starts (not after fade finishes), saves XP before map exit (actual KR6 GS.save_on_restart_and_quit=true), and uses existing scene transitions for confirmed restart/quit. Options resources predecode before pause is enabled. Debug outer header/footer/frame still exist and remain part of unfinished native presentation.

## Validation scope

- Core native comparisons cover42 callback states and14 slider poses; fake Web Audio regression verifies independent bus updates, pitch/loop offset continuity, delayed playback, new UI voices during pause and cleanup. These are meaningful audio-state checks, not proof of full event/sample parity.
- `browser_pause_options.mjs` uses a normal replay profile, visible native entry and real original game session. It checks frozen battle time, paused existing audio, keyboard/background/knob slider input, live/persistent volumes, toggle restoration, native restart/quit confirmation, cancellation, resume and actual restart/map transitions. It does not prove a natural-wave win or video parity.
- Full export/test/build and final browser results are recorded in VIDEO_OBSERVATIONS.md. Six natural flows through3-2 are still unproven; last probe remains four wins/two defeats.
