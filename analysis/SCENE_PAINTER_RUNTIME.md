# 原版场景绘制队列对照

继续上一轮血条排序修复。本轮把实际投射物、有限特效、烟雾、乌鸦阴影、墓碑接到原版帧的层级、排序位置、draw_order、实体 ID，并修正单位帧完全重合时的历史顺序。仍不是整个游戏或视频的最终验收。

## 原始依据

`all/systems.lua` 的 render insert/update 原始字节码，及其可读反编译 `analysis/functions/render_insert.lua`、`render_update.lua`：z 升序、sort_y 或 pos.y+sort_y_offset 降序、draw_order 升序、X 升序。完全相等时原版插入排序保持上一帧顺序。隐藏帧仍在队列内，隐藏血条不更新位置。

新增 `scripts/export_native_scene_paint.lua` 在原版实际运行中观察 `store.render_frames`，不替换模拟、render 或排序函数。导出每个对象的原始帧键、顺序、z、排序 Y、X、draw_order、透明度和隐藏状态。两组合法输入与既有原版状态对照共用同一配置与 LCG104；不能当作视频的随机流。

- `native-scene-paint-video-continued.json`：73 个检查点，15,418 个原始对象/血条帧。
- `native-scene-paint-survivor.json`：55 个检查点，12,063 个原始对象/血条帧。
- 两组原版执行均无缺失资源/动画。

## 具体修复

- 投射物：移除固定12000排序，读取模板的实际z3400及逐帧位置、排序覆盖和实体序号。静态模板使用 sprite.pos 时遵循该位置，而不是强制 entity.pos。
- 有限静态特效与已注册普通特效：移除10000/11000附近的人为偏移，使用实际模板z及原始实体/部件序号。例如法师命中z3301，其他常见命中特效z3300，低于z3400的飞行弹体。
- 落空暗影箭：原始 arrow update 会将通用decal_tween改为Z_DECALS=1400；渲染时保留这个运行时覆盖，不能照通用模板z3000绘制。
- 血泊：原始 enemy death 会继承死者第一精灵的z，并设置sort_y_offset=1。原先9999-Y在基本敌人的z3000场景下正好对应这一偏移；本轮保留该规则，并接通动态z与真实绘制序号。静态血泊模板的z1400不能直接用来替代死亡脚本的覆盖。
- 乌鸦阴影、烟雾及烟雾修饰器：去掉人为epsilon，读取原始精灵序号及绑定实体ID。乌鸦阴影为同一实体的第二帧。
- 塔：实际注册前渲染器可能缓存ID0，随后模板未变就不再刷新。现在每帧读取当前注册源ID；保留此前升级当帧旧塔继续绘制的规则。
- 单位完全重合：在原生第3373帧，两援军的血条坐标及draw_order完全相同，单靠浏览器网格创建顺序会倒置原版队列。`UnitPainterHistory` 按每个模拟tick更新单位帧，保持稳定排序，不依赖浏览器刷新频率；新帧按实际插入事件顺序附加。死亡、传送、特殊援军入场等隐藏血条保持其最后位置，初始隐藏帧保持原始零位置。历史只用于主排序键全等的情况。

## 已验证的范围

- 实际 normal GameSession 的完整原版胜利输入12000帧与复活输入6223帧保留状态/RNG/队列对照；其中73/55个采样点分别比对4925/3525个单位原始帧的稳定顺序，包含隐藏帧。不是只用网页比较器排序原版数据来验证实现。
- `verify_native_painter_order.mjs` 保留原三组受控原函数排序、四组原版开场队列，并增加73组混合场景/15418帧整体排序及sprite.pos覆盖。
- 实际Chrome胜利回归：8699tick、23700实体事件、1762个原版命名音效请求不变；73个绘制检查点，7264个实际提交帧与原版元数据和相对顺序一致。另检查314个血条网格、23765个EXO部件、1500组前排单位/后方血条关系。数量为跨检查点累计。

- 实际Chrome复活/传送回归：6223tick、14142实体事件、1105原版命名音效请求不变；55个绘制检查点，5184个实际提交帧与原版元数据/顺序匹配。另检查184个血条网格、16863个EXO部件和977组遮挡关系。这组输入自然败北，与原版结果一致，不能算作通关验收。
- 生产构建、完整npm test、两组Chrome进程及补强后的两组全单位历史对照均已结束，退出码0。补强对照根据原版单位名称枚举预期帧，并要求每帧都存在，避免用网页已存在的帧反向筛选预期集合。
- 浏览器报告为 `browser-native-full-battle.json` 与 `browser-native-survivor-battle.json`，实际队列检查统计在各采样点的paint字段。元数据检查拒绝缺失或非有限数值，最后两次强化检查均通过。测试日志为 `scene-paint-{build,tests,browser,survivor-browser,unit-history,survivor-history}.log`。复活4797截图已查看；测试页面使用debug入口便于控制，正常入口的全屏布局未变。

尚未将每个专用技能、粒子和UI渲染器都接入同一原始帧队列，也未完成全部可见像素/音频听感/视频输入和配置验收。帧键检查仅覆盖已接入且实际提交的对象；不能从这些数字推断全部原版帧已经显示。完全相等的非单位帧目前仍需进一步核对历史顺序。目标继续保持未完成。
