# 博林基础战斗与死亡复活：原版整链验收

范围为11星可达英雄的基础远攻、弹壳、粒子、普通死亡爆炸和复活。尚未开放正常界面换队，不代表博林完整实现或六流程验收完成。

## 原始依据与实现

- 从APK原始函数、模板、动画导出：初始等级2/1000经验，射击冷却严格大于2.75秒，19/30秒前摇直接比较浮点时间，开枪时写入攻击时间戳；保留目标，只在目标死亡/移除时重新选择。
- `BolinController.ts`拥有实际英雄main中的前摇/收尾。前摇中断当帧执行待机/回血，之后处于眩晕的外层main只执行待机，暂停回血计时和经验消费。
- `BolinNativeRuntime.ts`为基础弹体、命中EXO、弹壳控制器、弹壳、死亡控制器与范围伤害提供正式实体。伤害走共享队列；命中经验为实际伤害×0.8。
- 弹壳首次主脚本先分配粒子，再做三次随机；保留第二帧零积分、一次弹跳、落地动作、等待和原版线性透明度运算。粒子走真实粒子阶段。
- 原版死亡控制器在死亡协程开始前创建，延迟64/30秒产生爆炸；协程结束后控制器仍留在实体表。普通死亡没有墓碑，30秒等待后播放levelup复活动作。
- `BolinRenderer.ts`、`WizardFirebookRenderer.ts`使用原始图集/EXO和排序。正式实体的血条按生命周期与隐藏状态处理，HP归零不直接删除；没有实体调度的旧接口保留原有清理行为。
- `hero-team.json`记录原始初始等级、两格队伍、原版汉化名字和头像编号（博林为4）。`HeroTeam.ts`与ProgressStore支持11星解锁、换队最低经验、合法技能与队伍存档；UI装备入口仍待接入。

## 验证范围

- 13条基础整链11700帧：正/左/上/下/左上/左下、移动目标、发射前后目标移除、三个眩晕时点、没有目标。
- 另有普通死亡→延迟爆炸→复活→再次开枪的1100帧完整链，总计14条12800帧。
- 每帧验证真实GameSession的实体表/ID、插入删除队列、全部创建事件、随机调用、HP/经验/等级、英雄姿态/翻转/时钟、射击时间戳、回血计时、弹壳轨迹/落地/层级/透明度/补间及全部粒子状态，并逐次比较具名音效请求。
- 19组原版升级配置/190等级、54次原版队伍装备调用和234组英雄图算法回归通过。换队测试覆盖11星门槛、默认/自动队伍、异常存档和最低经验；不等于正常界面可选博林。
- Chrome基础900个绘制检查点：50109个实际场景排序元数据、11278个博林家族绘制条目；实际英雄/命中EXO各部件图集与透明度、弹壳图集/透明度、485次粒子图集提交匹配原版。
- Chrome死亡复活1100个检查点：61044个场景排序元数据、7555个家族条目，包括身体EXO、血条、命中、弹壳与粒子。正常HP与死亡时血条透明度均逐帧检查。
- 552个原版血条帧和552个稀疏绘制时钟状态通过。首次血条修正暴露的旧接口清理回归已修正。
- 浏览器共享输入脚本使用内容哈希参数加载，避免Vite排除scripts监听后复用旧驱动。旧驱动失败记录保留于`bolin-death-browser-stale-driver-red.log`。
