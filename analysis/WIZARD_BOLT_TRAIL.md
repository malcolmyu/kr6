# 普通法球拖尾与收尾生命周期

四级普通法球均使用原包 `ps_tower_wizard_bolt_trail`：50次/秒生成、60FPS非循环 `wizardproyectiletrail` 图集、固定1.2倍横纵缩放、随机[.9,1]秒粒子生命周期、跟踪旋转。配置已从原包导出至 wizard-bolt-trail.json，扩展既有 FirebookTrailSystem，普通法球与火炎法书共享图集粒子渲染器。

## 本次接入

- 原始法球主协程创建发射器，下一 tick 插入。保留严格生成时钟、插值和每粒子一次生命周期随机调用；不是按30Hz逻辑帧固定生成一个粒子。
- 命中后停止发射、隐藏弹体、保留弹体等待1秒，随后排队删除。粒子继续自然结束，源弹体移除后发射器才进入最终清理。生产版把 flight done 与 entity removal 分开，收尾期间不再次造成伤害。
- 发现此前仅比较位置/速度的夹具没有覆盖精灵朝向：原版 initial impulse 阶段的 last_pos 保持发射位置，起飞朝向因此取相对发射点的方向；进入转向后才逐步刷新 last_pos。命中步骤直接跳出循环，不更新本步朝向。现已按原始代码处理。
- 仍在本帧英雄战斗之后更新粒子；已结束的塔弹快照保留到该阶段，命中帧与下一帧的源实体有效性不被提前合并。
