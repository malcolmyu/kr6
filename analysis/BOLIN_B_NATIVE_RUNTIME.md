# 博林 B：地雷阵原版运行时

2026-11-18。正式 GameSession 已接入布雷控制器、抛射弹体、地雷、爆炸伤害与弹坑；原始 APK/Lua 回调作为行为依据。

## 行为

- 每次施法放置一枚地雷。波次开始后、附近无敌人且满足冷却时才尝试；保留原版路径节点顺序、三条子路径的重复候选权重、距离和间距判定。
- 三档容量为4/6/8；近处容量满或没有可用位置时锁住重试，爆炸后解除。全局容量达到上限时可强制引爆远处最远地雷。
- 飞行使用原始抛物线，落地生成地雷；布设40帧后待机，待机保留布设动画时钟。敌人进入触发范围后下一次协程恢复才引爆；强制标记也能在没有敌人时引爆。
- 保留原始施法前后摇、中断、经验结算、伤害查询、飞行单位筛选、爆炸22帧及弹坑生命周期；布设音效保留1秒延迟参数。
