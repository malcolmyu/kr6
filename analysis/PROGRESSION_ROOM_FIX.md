# 英雄／法术成长界面核对（2026-11-21）

## 已复现并修复

英雄技能房间将选中头像的group_xp_info永久隐藏，等级文字仍为原模板10；大面板label_lvl_number也未绑定真实XP。新增回归首先以1000XP期望2级得到10级而失败。现绑定真实等级和本级经验比例，恢复头像等级/经验区域，更新主面板同名字段；英雄起始XP与战斗端共用effectiveHeroXp（博林至少2级/1000XP）。

法术房间和战斗入场对初始等级的处理不一致：原生起始3级的锁定法术在房间被显示为1级。新增effectivePowerXp供两者共用；前三关三种可用法术原生都从1级开始，未改变其经验速率或阈值。

打开英雄房间改用统一saveSessionProgress，将最新经验落盘，而不是只更新内存progress。

- HeroRoom真实渲染树12组等级/经验/点数、PowerRoom15组阈值/满级及原始默认等级检查通过。
- 252组原始英雄经验倍率、20组等级属性、动画门禁和持久化通过。
- 4200组原始法术经验/等级/GUI比较、有效／无效施放、存档隔离通过。
- 51组法术补丁、357组技能树，实际GameSession中的冷却/陨石伤害/援军寿命/皇家范围/反伤应用通过。
- 234组英雄技能树、20组被动属性和实际英雄模板通过。
- CUA只读核对当前本地存档：杰拉尔德39XP、1级、0点；援军1级、0点。修正后的实际英雄页显示1，与存档相符。未改用户经验、关卡或购买任何技能。

法术按成功施放积累经验；升级提供技能点，技能树购买再决定技能效果。经验计算有原版对照，不以提高经验倍率来掩盖显示问题。英雄房间的完整主面板/正常换队，以及博林未完成能力仍属整体还原剩余工作，不能据此宣布全目标完成。
