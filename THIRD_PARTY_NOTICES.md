# LuaJIT numeric entity table

`src/game/LuaEntityTable.ts` adapts the numeric-key table algorithms in LuaJIT `lj_tab.c` and `lj_tab.h`, pinned to upstream release commit `8271c643c21d1b2f344e339f559f2de6f3663191` (2.1.0-beta3).
